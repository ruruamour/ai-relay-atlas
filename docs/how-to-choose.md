# 怎么选上游 / 怎么避免踩坑

## 选中转站（API）
1. **先看默认分组的实际价**，不要被福利组低价骗。
2. 确认**模型真实性**：拿到 key 后请求 `/v1/models`，再小额实测。
3. 看**稳定性**：Veridrop 等公开测评分、可用率。
4. 看**计价方式**：按 token 还是按次；有没有 `billing_expr`。
5. Aistudio 渠道通常比 Vertex 便宜；标 Vertex/企业版的更贵但也更稳。

## 选发卡店（账号/会员）
1. **先分清买的是什么**：车位（共享）/ 成品号 / 代充 / CDK。
2. **读质保条款**：质保多久、掉车怎么赔。
3. **看店铺**：销量、经营时长、有无售后群。
4. **小额试单**，别一次买大额。
5. 家庭组席位是**共享**，不是独立号。

## 通用原则
- 所有价格以**原站实时页面**为准。
- 低得离谱的价格，先怀疑是不是福利/引流或渠道货。
- 账号类商品有封号风险，做好心理准备。
