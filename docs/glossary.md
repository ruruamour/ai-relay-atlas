# 黑话表

## 交付与质保
| 词 | 含义 |
|---|---|
| 车位 / 席位 | 家庭组里共享的一个名额，不是独立账号 |
| 拼车 / 合租 | 多人分摊一个订阅 |
| 车长 / 主号 | 开家庭组的主账号，可拉若干成员 |
| 成品号 | 已开通好权益的账号，拿来就能用 |
| 代充 | 用你的账号帮你开通订阅 |
| CDK / 兑换链接 | 卡密或链接，自助兑换权益 |
| 首登 | 只保证第一次登录成功 |
| 质保 / 质保30天 | 出问题在期限内可售后 |
| 掉会员 / 掉车 | 权益被官方回收 |
| 无质保 / 不售后 | 风险自负 |

## 渠道与技术
| 词 | 含义 |
|---|---|
| SSO | 账号的登录令牌，导入即可用（风险高） |
| RT / AT | Refresh Token / Access Token |
| CPA / SUB2 / gro2 | 各类把账号转成 API 的格式/工具 |
| 反重力 / Antigravity | Google 的 AI IDE，Grok/Gemini 相关渠道常挂它 |
| Aistudio | Google AI Studio 渠道（较便宜） |
| Vertex | Google Cloud Vertex AI 渠道（较贵、企业级） |
| 中转站 | 转卖各模型 API 的代理站 |
| 倍率 | 中转站对模型价格的乘数 |
| 福利组 | 低价/免费分组，通常限流、不稳 |
| 轮转车 | 多个账号轮流供一个车位 |
| 接码 | 用第三方手机号接收验证码 |

## 发卡生态
| 词 | 含义 |
|---|---|
| 发卡 / 卡网 | 自动发货卖虚拟商品的站 |
| 发卡平台 | SaaS，商家入驻（链动小铺等） |
| 发卡系统 | 开源软件，自建用（独角数卡/异次元发卡等） |
| 引流款 | 低价噱头商品，未必有货 |
| JIO / Pixel 渠道 | Gemini Pro 年卡的两种常见来源 |
